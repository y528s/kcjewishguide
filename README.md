# Guide to Jewish Life in KC

Your complete guide to Jewish life in Kansas City — kosher food, synagogues, schools, and community resources.

**Live site:** https://y528s.github.io/kcjewishguide/

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)

## Local Development

```sh
npm install
npm run dev
```

Opens at http://localhost:8080

## Build

```sh
npm run build
npm run preview
```

## Deployment

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.
